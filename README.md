## Cómo Usar el dashboard.py

### Requisitos:

Python 3.x instalado en tu sistema.

### Ejecución:

Abre tu terminal o línea de comandos.

Navega a la carpeta raíz del proyecto (ESTEFANIA_SEMESTRES2_PARALELOA_POO). Asegúrate de que la ruta_base_proyecto en dashboard.py coincida con la ubicación real en tu máquina:

### Python

ruta_base_proyecto = r"C:\Users\milen\PycharmProjects\ESTEFANIA_SEMESTRES2_PARALELOA_POO"
Si tu carpeta está en otra ubicación, actualiza esa línea en dashboard.py antes de continuar.

### Ejecuta el script dashboard.py:

Bash

python dashboard.py
Interacción:
El menú principal te permitirá seleccionar una semana por su número.

Dentro de cada semana, podrás seleccionar un script para:

### Ver su código en la terminal.

Ejecutarlo en una nueva ventana (comportamiento varía entre sistemas operativos, abriendo cmd en Windows o xterm en sistemas basados en Unix).

Usa 0 en cualquier menú para regresar a la opción anterior o para salir del programa.
