# UNIVERSIDAD ESTATAL AMAZONICA
## SEGUNDO SEMESTRE DE LA CARRERA DE TECNOLOGÍAS DE LA INFORMACIÓN

### Descripción del Código

Este proyecto simula el ciclo de vida de dispositivos tecnológicos, implementando los principios de la Programación Orientada a Objetos (POO) en Python. A través de este sistema, se gestionan el ingreso y la salida de dispositivos como laptops y móviles, utilizando constructores y destructores para manejar automáticamente la creación y eliminación de objetos.

### Herramientas Utilizadas

- **Constructor (`__init__`)**: Método especial que se ejecuta al crear una instancia de la clase. Se utiliza para inicializar los atributos del objeto y registrar el ingreso del dispositivo.
  
- **Destructor (`__del__`)**: Método especial que se ejecuta automáticamente cuando un objeto es eliminado de la memoria. Se utiliza para liberar recursos y registrar la salida del dispositivo.

## Características Clave

✔️ Simulación del ingreso/retiro de dispositivos  
✔️ Ejemplo práctico de constructores y destructores  
✔️ Implementación limpia y didáctica  
✔️ Documentación clara y concisa
